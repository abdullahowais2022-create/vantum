# Vantum

A quality-of-life Minecraft launcher and client, made by **Velorix Web Studio**.

Sign in with your Microsoft account, create instances (each with its own version,
mods and worlds), browse and install mods from Modrinth in one click, and play —
with an in-game HUD, HUD editor, zoom, fullbright and more (press **Right Shift**
in game).

## Download

Grab the latest **Vantum-Setup** installer from the
[Releases page](https://github.com/abdullahowais2022-create/vantum/releases/latest).

1. Download `Vantum-Setup-x.x.x.exe`
2. Run it. Windows may show "Windows protected your PC" because the app isn't
   code-signed yet — click **More info → Run anyway**.
3. Open Vantum, **Sign in with Microsoft** (your own account — you need to own
   Minecraft: Java Edition), create an instance, and press **Play**.

Vantum keeps everything in its own folder (`%APPDATA%\Vantum`) and never touches
an existing Minecraft install.

## Updates

Vantum updates itself. When a new version is released here, the launcher
downloads it in the background and shows a **Restart** button — no reinstalling.
